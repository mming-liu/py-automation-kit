# 运行说明（交付版）

本文档随脚本源码一并交付，供使用方在自己的电脑上独立运行，不需要联网。

## 一、准备

1. 安装 Python 3.8 或更高版本（安装时勾选 **Add Python to PATH**）。
2. 验证安装：

   ```bash
   python --version
   ```

   能看到 `Python 3.x.x` 即可，不需要安装任何第三方包。

3. 把整个 `py-automation-kit` 文件夹复制到本机任意位置（路径建议不含空格）。

## 二、一分钟验证

在本文件夹内打开命令行，执行：

```bash
python cli.py demo
```

预期看到 5 个步骤依次完成，并在 `workspace/out/` 下生成：

| 文件 | 含义 |
| --- | --- |
| `rename_plan.csv` | 重命名预览表（旧名 → 新名、日期来源） |
| `merged_sales.csv` | 三份门店报表合并结果 |
| `orders_synced.csv` | 从接口同步下来的订单 |
| `api_sync.log` | 同步日志，逐页记录与重试明细 |
| `daily_report.md` | 本次批处理的运行日报 |

## 三、常用操作

### 1. 批量重命名（最常用）

先预览，**不会改动任何文件**：

```bash
python cli.py rename --dir "D:\照片\2024" --pattern "*.jpg"
```

打开生成的 `workspace/out/rename_plan.csv` 核对「旧名 → 新名」。确认无误后加 `--apply` 执行：

```bash
python cli.py rename --dir "D:\照片\2024" --pattern "*.jpg" --apply
```

模板占位符：

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{date}` | 从文件名或修改时间推断的日期 | `2024-07-15` |
| `{seq}` / `{seq:03d}` | 序号 | `7` / `007` |
| `{name}` | 原文件名（不含扩展名） | `IMG_20240715_093012` |
| `{ext}` | 扩展名 | `.jpg` |
| `{parent}` | 所在文件夹名 | `2024` |

默认模板 `{date}_{seq:03d}{ext}`，产出 `2024-07-15_001.jpg` 这类结果。

**安全机制**：若模板产出重名，程序会列出冲突并中止，不会覆盖已有文件。

### 2. 合并多个表格

```bash
python cli.py merge --inputs a.csv b.csv c.csv --out 合并结果.csv
```

- 表头不一致时按并集对齐，缺失字段留空
- 每行追加 `来源文件` 列，便于追溯
- 加 `--dedupe order_id` 可按指定列去重

### 3. 按列拆表

```bash
python cli.py split --input 总表.csv --by region --out-dir 分区文件
```

### 4. 生成日报

```bash
python cli.py report --title "9月批处理日报"
```

常驻查看 Mock 接口（浏览器可访问，Ctrl+C 停止）：

```bash
python cli.py mock            # 默认 http://127.0.0.1:52154/
```

## 四、自测

```bash
python cli.py selftest
```

全部显示 `ok` 表示环境正常。若出现失败，请把完整输出发给我们。

## 五、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `'python' 不是内部或外部命令` | Python 未加入 PATH | 重装勾选 Add to PATH，或用 `py` 代替 `python` |
| 中文显示为乱码 | 终端编码不是 UTF-8 | 用 Windows Terminal / Git Bash，或先执行 `chcp 65001` |
| Excel 打开 CSV 乱码 | 文件被其他工具转成了 ANSI | 本工具默认输出带 BOM 的 UTF-8，正常情况不会乱码；如已乱码请重跑 |
| `存在命名冲突，已中止执行` | 模板里没用 `{seq}`，多个文件算出了同一名字 | 在模板中加入 `{seq:03d}` |
| 接口同步报 `连续失败` | 目标服务不可达或返回 5xx | 检查网络与接口地址；日志 `workspace/out/api_sync.log` 有逐次记录 |
| 浏览器打开同步日志里的 `http://127.0.0.1:xxxxx` 提示拒绝连接 | Mock 接口只在命令运行期间存在，同步结束自动关闭，属正常设计 | 想在浏览器查看接口：运行 `python cli.py mock` 并保持窗口开启，访问 `http://127.0.0.1:52154/`；用完 Ctrl+C 停止 |

## 六、修改与扩展

- 新增一个自动化任务：在 `kit/` 下加一个模块，导出处理函数，再在 `cli.py` 的 `build_parser()` 里注册子命令。
- 字段映射、模板、过滤规则都通过命令行参数传入，不需要改代码即可适配新场景。
